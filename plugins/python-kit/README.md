# python-kit

Python expertise, reusable across Python projects (scripts, services, libraries).

## Included
- `skills/python-best-practices` — rules by topic: style, typing, errors, data modeling,
  functions/classes, async, testing, packaging/tooling, performance, security.
- `skills/fastapi-best-practices` — FastAPI rules: structure, routes/dependencies, schemas,
  database, errors, security, testing, performance/deploy, PydanticAI.

Target stack: Python 3.12, FastAPI, Uvicorn, SQLAlchemy 2 (sync), Alembic, psycopg 3, PydanticAI.
